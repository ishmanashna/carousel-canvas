# 03.1 — cutter, then box the hole

One photo. Person-cutter once. SAM-box + clip + union for missing subject bits. Then lift. No wipe. No cleanup.

Work at long-side **2048**, then `lift-alpha`. The grid is **12 cells** on that 2048 photo (4×3 if landscape, 3×4 if portrait). Cell labels are the `--xyxy` pixels.

## Placeholders

- Input: `{{INPUT}}`
- Out: `{{OUT_DIR}}`

## Subject

Every complete person in the frame, plus what they are holding. Several people is fine when each is a clean silhouette. A scrap of another person is leftover for a later pass; do not fail the photo over it.

## Bans

No keys, Photoshop-class apps, `crates/vision`, GUI, strip, commit, pip, clone, venv, `.cursor/mcp.json`. No `isnet-general-use`. No second rembg model. No full-image SAM instead of the body. Quote `--xyxy`. Do not read other photos’ cutouts for coordinates.

**Do not** run `wipe`, `wipe-islands`, or `erase-alpha`. Do not trim specks, carve silhouettes, or drop “junk” islands. Leftover background and floaters stay. You only add missing subject via SAM; you never subtract.

## Commands

From repo root (PowerShell `;` not `&&`):

```powershell
$sx = "tools\subject-extract\sx.ps1"
New-Item -ItemType Directory -Force "{{OUT_DIR}}" | Out-Null
$env:SX_ACTS_LOG = (Join-Path (Get-Location) "{{OUT_DIR}}\ACTS.jsonl")
& $sx doctor
& $sx work-prep --max-side 2048 "{{INPUT}}" "{{OUT_DIR}}"
& $sx grid "{{OUT_DIR}}\work_orig.png" "{{OUT_DIR}}\grid.png"
& $sx rembg --model birefnet-portrait "{{OUT_DIR}}\work_orig.png" "{{OUT_DIR}}\cutout.png"
& $sx checker "{{OUT_DIR}}\cutout.png" "{{OUT_DIR}}\cutout_checker.png"
& $sx crop --xyxy "x1,y1,x2,y2" "{{OUT_DIR}}\work_orig.png" "{{OUT_DIR}}\region_orig.png"
& $sx crop --xyxy "x1,y1,x2,y2" "{{OUT_DIR}}\cutout.png" "{{OUT_DIR}}\region_cut.png"
& $sx sam-box --xyxy "x1,y1,x2,y2" --prompts "{{OUT_DIR}}\prompts.json" "{{OUT_DIR}}\work_orig.png" "{{OUT_DIR}}\donor.png"
& $sx clip-alpha --xyxy "x1,y1,x2,y2" "{{OUT_DIR}}\donor.png" "{{OUT_DIR}}\donor.png"
& $sx union --image "{{OUT_DIR}}\work_orig.png" "{{OUT_DIR}}\cutout.png" "{{OUT_DIR}}\donor.png" "{{OUT_DIR}}\cutout.png"
& $sx keep-best promote "{{OUT_DIR}}"
& $sx keep-best restore "{{OUT_DIR}}"
& $sx lift-alpha --image "{{INPUT}}" --meta "{{OUT_DIR}}\work_meta.json" "{{OUT_DIR}}\cutout.png" "{{OUT_DIR}}\cutout_full.png"
& $sx checker "{{OUT_DIR}}\cutout_full.png" "{{OUT_DIR}}\cutout_full_checker.png"
```

`prompts.json`:

```json
{
  "sam_prompt": [
    {"type": "point", "data": [x, y], "label": 1},
    {"type": "point", "data": [x, y], "label": 0}
  ]
}
```

Label `1` = on the missing bit. Label `0` = off it. `sam-box` also needs `--xyxy`.

doctor fail or exit `10`/`12` → **BLOCKED**. `ort_providers` must include `DmlExecutionProvider`.

`sx rembg` already retries (new process, 60s cooldown, up to 8). If it still returns empty: wait **3 minutes**, run `sx rembg` again. Do **not** mark BLOCKED and skip the photo — keep going until there is a seed, unless `doctor` failed. Do not retry in a tight loop. BLOCKED is only for doctor / missing weights / no GPU.

## Loop

1. `doctor` → `work-prep` → `grid`. Read `grid.png` and `grid_meta.json` (12 cells + pixel boxes).
2. `rembg --model birefnet-portrait` on `work_orig.png` → checker → `keep-best promote`.
3. Name missing subject bits. `crop` that cell from `work_orig` and `cutout`. If nothing is missing, skip to lift.
4. Tight box around **only** the missing bit. `sam-box` → `clip-alpha` → `union` → look.
5. Better → promote. Worse → restore, one change. At most **4** `sam-box` calls. Stop when the bits are there, or when more SAM would not help.
6. `lift-alpha` → checker `cutout_full.png`. Stop. Do not wipe. Do not reopen the cutout to “clean” it.

## Done

Always write `REPORT.md` (even **BLOCKED**) and finish `TIMING.md` from `ACTS.jsonl`. Leave `cutout_full.png` when you have a seed.

### Verdict (be generous)

- **WORKS** — subject (+ held kit) is mostly there and usable on a carousel. Extra specks, leftover background, or a slightly rough edge is still WORKS.
- **PARTIAL** — usable seed but something important is clearly wrong (big hole in the person, major held instrument missing).
- **FAIL** — unusable.
- **BLOCKED** — doctor / GPU / weights; not a taste call.

Prefer WORKS when you would actually use the cutout. One WORKS in ten was too harsh. Do not fail a cutout because leftover junk was not wiped — wiping is banned.
